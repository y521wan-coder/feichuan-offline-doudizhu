# 测试与验收

## 确定性 AI 场景

必须覆盖：无危险时让队友单牌/对子；不用炸弹压队友；队友剩一张/两张时创造机会；地主剩一张时守门；立即出完例外；压地主使用最低代价；无力拦截时为后位保留控制牌；改变不可见暗牌后同一观察和种子决策不变。

## 自动模拟

每等级至少 10000 局，要求零非法出牌、零无法结束、零越权暗牌读取、非例外炸弹压队友为零、非紧急高牌压队友率接近零。输出地主/农民/座位胜率、让牌率、守门成功率和异常记录。
