# Windows 无障碍规格

- 动态游戏公告优先交给当前运行读屏的官方接口：NVDA Controller Client、保益 `byctrl-x64.dll` 或争渡 `ZDSRAPI_x64.dll`；一次只选择一个后端。
- NVDA 客户端 DLL 随游戏分发；保益和争渡从各自官方安装目录加载接口，不复制或修改读屏文件。
- 没有受支持的官方接口时使用 Qt Widgets/UIA 传统焦点事件兜底，兼容 Windows 讲述人且不改变真实键盘焦点。
- 已拿起牌退出浏览序列，放下后恢复到正确位置。
- 左/右与 Shift+左/右都按未拿起牌的点数组浏览；同一点数不因实体牌张数重复停留或重复朗读。
- 手牌只读张数与点数，例如“3张10”“2张K”；不读花色、位置、总张数或拿起状态。
- 拿起或放下一张时朗读该牌点数；整组拿起或全部放下时复用左右浏览的同一套“张数+点数”文本（如“三张三”），同时保留简短操作音效。
- 可视牌桌为纯显示层，不获取键盘焦点、不响应鼠标，不替换手牌列表、Qt/UIA 焦点事件或既有快捷键路径。
- 出牌播报包含完整主体和附带牌；下一家 AI 等待必要播报结束。
- 过牌只播放对应声线音效，不生成冗余公告。
- 同一事件只走当前读屏官方接口或 Qt/UIA 兜底中的一条路线，避免重复朗读。
- 发布前使用 NVDA、讲述人、争渡和保益人工回归。
