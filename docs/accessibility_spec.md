# 无障碍规格书

## 设计目标
- 不看屏幕也能理解游戏阶段
- 所有交互控件提供正确的无障碍属性
- 通过 NVDA、保益、争渡的官方朗读接口和 Windows Qt/UIA 标准兜底支持常用读屏与讲述人
- 不泄漏隐藏信息

## 后端
- NVDA Controller Client：随程序分发官方 x64 DLL，运行时动态加载
- 保益：从保益安装目录动态加载官方 `byctrl-x64.dll`，使用独立朗读通道
- 争渡：从争渡安装目录动态加载官方 `ZDSRAPI_x64.dll`
- Qt/UIA 传统控件焦点事件：无官方接口可用时的标准兜底
- 同一公告只提交给一个后端，关闭播报时使用 Null 后端

## 播报优先级
- Critical：游戏结束、严重错误
- High：轮到真人、炸弹
- Normal：其他玩家出牌
- Low：背景提示

## 隐私
- AI手牌不创建可访问子项
- 发牌完成进入叫分阶段时，底牌保持隐藏；地主确定后，二人/三人模式的 3 张或四人模式的 8 张底牌才进入无障碍播报和 F2 查询。二人模式的 17 张盖牌始终不播报。
- 动态状态始终更新现有状态控件的可访问名称；优先调用当前运行读屏的官方接口，调用成功后不再发送 Qt/UIA 朗读事件。
- 官方接口不可用时发送传统 `QAccessible::Focus` 事件；不调用 `setFocus()`，不改变真实键盘焦点。
- 不再发送 `QAccessibleAnnouncementEvent`，避免不支持 UIA Notification 事件的读屏完全无声，也不同时发送两种路线造成重复朗读。
- Debug日志默认关闭
