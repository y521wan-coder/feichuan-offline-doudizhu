# 无障碍规格书

## 设计目标
- 不看屏幕也能理解游戏阶段
- 所有交互控件提供正确的无障碍属性
- 通过 Windows Qt/UIA 标准无障碍支持 NVDA、保益、争渡和讲述人
- 不泄漏隐藏信息

## 后端
- Qt/UIA传统控件焦点事件（动态状态朗读）
- 不加载或调用任何读屏官方接口 DLL
- Null后端（关闭播报）

## 播报优先级
- Critical：游戏结束、严重错误
- High：轮到真人、炸弹
- Normal：其他玩家出牌
- Low：背景提示

## 隐私
- AI手牌不创建可访问子项
- 发牌完成进入叫地主阶段时，八张底牌立即作为公开信息进入无障碍播报和 F2 查询。
- 程序固定使用 Qt/UIA 标准无障碍，不初始化争渡、保益或 NVDA 官方接口。
- 动态状态更新现有状态控件的可访问名称，并发送传统 `QAccessible::Focus` 事件；不调用 `setFocus()`，不改变真实键盘焦点。
- 不再发送 `QAccessibleAnnouncementEvent`，避免不支持 UIA Notification 事件的读屏完全无声，也不同时发送两种路线造成重复朗读。
- Debug日志默认关闭
