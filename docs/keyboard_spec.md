# 四人斗地主快捷键规格

本文档记录当前采用的键盘操作基线。该基线参考用户既有“玩儿吧”四人斗地主项目，并按用户最新要求补充 F5 设置入口。

## 主流程

| 按键 | 功能 |
|------|------|
| Tab / Shift+Tab | 只在游戏、设置、帮助三个顶层菜单间正向/反向循环 |
| F1 | 未开局时开战；牌局进行中停战；停战后恢复；结算页打开时不开始下一局 |
| F5 | 打开设置选项 |
| F11 | 叫分或出牌阶段只显示并播报当前玩家的自定义名称；无活动回合时静默 |
| F12 | 显示最后一次实际出牌 |
| ESC | 关闭当前菜单或对话框；活动牌局中立即放弃残局；结算页返回未开战主界面；主界面不退出软件 |

## 手牌浏览和拿牌

| 按键 | 功能 |
|------|------|
| 左/右光标 | 按组浏览尚未拿起的实体牌，光标停留在每组最左一张牌 |
| Home/End | 跳到尚未拿起牌的第一组/最后一组 |
| Shift+左/右光标 | 单张浏览尚未拿起的实体牌 |
| 上光标 | 逐张拿起当前牌，读屏保持静默 |
| Ctrl+上光标 | 拿起当前组牌 |
| 下光标 | 按拿起顺序放下一张牌，并恢复到正确点数组和浏览顺序 |
| Ctrl+下光标 | 放下全部拿起的牌 |

## 出牌和过牌

| 按键 | 功能 |
|------|------|
| 回车 | 出牌 |
| 空格 | 过牌；仅在正式出牌阶段轮到自己时生效 |

## 查询

| 按键 | 功能 |
|------|------|
| Alt+大键盘 1 | 查看一号座位（真人自己）身份和剩余手牌，播报自定义名称 |
| Alt+大键盘 2 | 查看二号座位身份和剩余手牌，播报自定义名称 |
| Alt+大键盘 3 | 查看三号座位身份和剩余手牌，播报自定义名称 |
| Alt+大键盘 4 | 查看四号座位身份和剩余手牌，播报自定义名称 |
| F2 | 查看8张公开底牌；叫分阶段即可使用 |
| Alt+F | 查看分数、基础分和倍数 |
| Ctrl+Q / Alt+F4 | 退出软件 |

## 设置

- F5 打开设置选项。
- 顶层只保留“游戏(G)”“设置(S)”“帮助(H)”三个菜单。Tab 负责菜单焦点循环；Alt+G、Alt+S、Alt+H 已释放，不再直接打开菜单。
- “设置”菜单包含玩家名称设置、音效与程序设置、真人声线和背景音乐；玩家名称设置子菜单支持回车或右光标展开。
- 设置中可调整真人超时自动过牌：最小 3 秒，最大 1800 秒，默认开启 30 秒。
- 等待时间单按上/下光标每次调整 1 秒；按住上/下光标可连续加速调整。
- 机器人模式包括初级、中级、大师级，全部使用本地逻辑。
- 背景音乐默认关闭，拥有独立音量和自动/背景音乐/普通/激昂模式；自动模式按主界面及结算、叫分、出牌、暂停切换。

## 兼容说明

- Alt+数字查询按 Windows 大键盘虚拟键 `1/2/3/4` 处理，按绝对座位编号查询；小键盘 `VK_NUMPAD1/2/3/4` 不触发。
- 上光标只负责拿起牌，不负责取消；Ctrl+上光标准确拿起当前完整点数组并与已有选择累加，重复操作保持原选择；下光标按拿起顺序逐张放下，Ctrl+下光标一次放下全部。
- 已拿起实体牌立即退出左右、Shift+左右、Home/End 浏览序列和同点张数；放下后重新加入。
- 手牌浏览播报采用玩儿吧格式，只读张数和点数，例如 `1张3`、`2张4`、`3张7`、`1张钩`、`1张圈`、`2张k`。
- 所有牌相关播报都不读花色，不读第几张、总张数、已拿起或未拿起。
- 上、Ctrl+上、下、Ctrl+下执行拿放牌时，读屏完全静默；原有拿起和放下游戏提示音保留。普通左右分组浏览仍正常朗读，例如 `3张10`。
- 对方组合牌的状态栏与读屏播报必须包含全部主体牌和附带牌，下一家 AI 行动需等待当前播报时间。
- 快捷键仅在四人斗地主位于前台时全界面有效，不注册会抢占其他软件按键的系统全局热键。选牌、放牌和出牌类按键忽略自动重复，保证一次物理按键只执行一次。
- 当焦点位于菜单栏、菜单、弹出控件或模态对话框时，Windows 低级键盘钩子和原生消息兜底必须让出方向键、回车和空格，由 Qt 标准菜单处理；顶层菜单和子菜单 QAction 的默认动作同时显式连接展开逻辑，保证 NVDA 的 UIA Invoke 可以打开菜单。
- 空格键手动过牌沿用现有规则，自由领出时也允许过牌；叫分阶段的空格仍用于确认当前叫分按钮。
- Alt+D 和 Ctrl+回车不再执行游戏功能，也不再由程序注册或拦截。
- 真人和 AI 过牌只播放对应声线的“不出/过牌”音效，不更新状态栏，也不发送读屏公告。
- 超时自动过牌按用户要求处理：即使轮到真人领出，倒计时结束也会自动跳过，不替用户出牌。

## 菜单与结算

- 游戏菜单：开战、停战/恢复、暂停/恢复、退出。
- 设置菜单：程序设置、玩家名称、真人声线、音效/音乐、软件更新。
- 帮助菜单：快捷键、玩法说明、关于。
- 结算列表持续显示胜方、地主、基础分、最终倍数、春天/反春和四名自定义玩家本局得分；上下光标逐项浏览，ESC 关闭并回到未开战主界面。
- 未完成牌局不再自动或手动存档，Ctrl+S、Ctrl+L 和恢复上次牌局入口已移除；启动时静默删除旧自动存档。
