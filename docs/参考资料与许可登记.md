# 参考资料与许可登记

| 内容 | 来源 | 权利/许可 | 使用方式 |
|---|---|---|---|
| 游戏基础源码、测试、文档 | 用户自有“飞船AI斗地主单机版-开源版” | 用户拥有完整版权 | 迁移并定向重构 |
| 图片、背景、音乐、音效 | 用户自有旧项目素材 | 用户声明拥有使用与重构权利 | 原样迁移，后续逐项复核 |
| GitHub 斗地主参考项目 | 外部公开项目 | 仅作行为研究，具体链接待用户登记 | 只转化合作行为需求，不复制源码、APK 或资源 |
| 可视扑克牌面与牌背 | 本项目使用 Qt 绘图原创生成 | 项目自有代码，无外部图片素材 | 运行时绘制点数、花色、牌面、牌背与双副牌标记 |

任何新第三方依赖或素材必须先补充项目、版本、链接、许可证、用途和落盘文件。
