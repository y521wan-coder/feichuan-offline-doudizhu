# 快捷键规格

## 自定义快捷键

- 以下全部现有游戏快捷键都可以在“快捷键设置”中修改，旧设置缺少自定义项时继续使用原默认值。
- 入口位于菜单栏第 4 项：按一下 Alt 键进入菜单栏，再用跳格键切到“快捷键设置”，按回车键进入。
- 对话框使用上下光标键浏览功能，按回车键开始修改；进入按键列表后继续用上下光标键浏览，按空格键选中或取消。单键选择一个普通键；组合键选择一个普通键并可同时勾选 Control、Shift 或 Alt。随后用跳格键切到“使用这个热键”，按回车键确认该绑定，最后回到功能列表并用“确定”保存全部设置。
- 除用户已经熟悉的 `Shift`、`Control`、`Alt` 三个修饰键保留英文外，其他功能名称、按键名称、冲突提示和按钮均使用中文；例如键盘上的下翻页按键显示为“下翻页键”，确认按键显示为“回车键”。
- 同一个按键或组合键不能同时绑定两个功能。发生冲突时显示已占用该按键的中文功能名，用户换一个按键后再保存。
- 自定义结果写入本机既有设置文件，并同时应用到 Qt 快捷键、Qt 键盘事件、Windows 原生消息、低级键盘钩子和既有系统热键兼容路径。
- 跳格键和 Shift 加跳格键也可以绑定为游戏快捷键：用上下光标键浏览到“跳格键”并按空格勾选，需要 Shift 组合时再勾选 Shift。菜单栏和普通对话框中的跳格导航保持不变；Alt+F4 继续作为 Windows 标准关闭键。

## 默认快捷键

- 左/右：按点数组浏览未拿起实体牌。
- Shift+左/右：逐张浏览。
- Home/End：第一组/最后一组。
- 上：拿起当前一张；Ctrl+上：拿起当前完整点数组。
- 下：按拿起顺序放下一张；Ctrl+下：全部放下。
- 拿起或放下一张时朗读该牌点数；整组拿起或全部放下时复用左右浏览的“张数+点数”格式朗读本次操作的全部牌，例如“三张三”，不使用“个”。
- Enter：出牌；Ctrl+Enter：过牌；空格键在出牌阶段不执行操作。
- 选牌键忽略自动重复；拿放牌时保留操作音效。
- F2：叫分阶段朗读“底牌尚未公开”；地主确定后朗读二人/三人模式的三张或四人模式的八张公开底牌，之后可重复查询。
- 大键盘 1/2/3/4：查询对应位置的玩家信息；查询超过当前有效人数的席位时明确提示该模式没有对应玩家。轮到真人叫分时，0/1/2/3 仍优先执行不叫或叫分，避免破坏叫分操作。
- Alt+1/2/3/4：已取消，不注册 Windows 热键，也不触发游戏内玩家信息查询。

其余快捷键沿用旧版行为，详细回归矩阵在无障碍测试阶段从旧测试生成。
