# 架构说明

- `src/core`：二人/三人 54 张与四人 108 张本地规则、状态机、计分和公共快照。固定数组容量仍为四席，`activePlayerCount` 决定本局实际参与席位，保证旧四人存档和接口兼容。二人局双方各 17 张、底牌 3 张，其余 17 张只在发牌时跳过，不保存为可观察状态。
- `src/ai`：只接受 `AiObservation` 的地主策略、农民团队策略、叫分、合法动作生成、`StrategicSearchEvaluator`、`FullInformationSearch` 和保留的 `ImperfectInformationSearch`。`StrategicSearchEvaluator` 负责全候选快速牌型评估与本家拆牌束搜索；`FullInformationSearch` 是 1.7 起的默认整桌推演器，直接用 `AiObservation::fullInformation` 里的真实手牌在复制牌桌上做带硬截止时间的极大/极小搜索加有限轮次推演，残局切换为更深的同队极大/敌队极小搜索，并把结果合并到候选排序；`ImperfectInformationSearch` 只在显式测试模式下使用，仍在公开信息生成的假设牌局上推演。三个策略档位可调的是搜索预算、根候选数、节点预算、推演轮数、候选裁剪和安全随机度，团队强制规则完全一致。
- `src/accessibility`：公告调度和 Windows 读屏兼容路径。NVDA、保益、争渡继续使用各自既有接口；检测到 Windows 讲述人且没有其它可用私有接口时，使用 Qt 6.8 的标准 UIA Announcement 事件，未命中时保留原 UIA 焦点事件兜底。
- `src/ui`：Qt Widgets 界面与键盘交互；`CardTableWidget` 只接收公共快照、真人手牌和选中牌 ID，以程序绘图方式提供无鼠标交互的可视牌桌。
- `src/persistence`：本地设置、统计、回放和诊断。
- `src/audio`：后续从 UI 中逐步抽离的音频边界。
- `src/app`：游戏应用组合根，不包含网络客户端。
- `apps/updater`：唯一允许链接 Qt Network 的独立 Windows 更新器。

核心安全边界是 `AiObservation`：1.7 起 `makeAiObservation` 除本家手牌和 `PublicGameSnapshot` 外，还注入 `AiFullInformation`（真实整桌手牌、真实底牌，以及二人模式在局外的 17 张盖牌），并在写入前逐张校验牌 ID 合法、不重、不超人数牌堆容量；校验失败时 `available=false`，全知推演自动退出。策略仍不得持有 `GameState`、`FullGameState`、洗牌种子或未来牌序，真实完整状态不会越过这个结构进入 AI。

全知推演的输入与边界：`FullInformationSearch` 只复制 `AiObservation` 中的真实手牌，不接触引擎本身；它按当前行动者在复制牌桌上生成合法动作、按难度裁剪候选、执行带节点预算与截止时间的搜索和推演，并在推演中继续套用农民强制协作规则（能立即出完、队友已胜不压、地主一张必拦、不炸队友），所以搜索不会推翻安全规则。结果只影响当前决策的候选排序，不写回牌局、不进入回放或统计。保留的公开信息模式仍只从本家手牌、已打出的牌、公开底牌、公开剩余张数、叫分和过牌状态生成可能分配，相同公开观察与种子得到相同结果。

二人模式的未参与盖牌在全知模式中如实存放在 `AiFullInformation::setAsideCards`，不会分配给任何玩家，也不会进入公共快照、可视牌桌或诊断日志；公开信息模式仍只把它当作未分配余量。所有推演中的临时局面仅存在于单次决策求值内。农民强制协作过滤在全知搜索之前执行，所以不压队友、立即出完和地主一张必须拦截等安全规则不被搜索覆盖。真人可见范围不变：可视牌桌、朗读和公告仍只依据公共快照、真人手牌和选中牌。

可视牌桌遵守同一隐藏信息边界：只显示当前有效电脑席位在 `PublicGameSnapshot` 中的剩余张数与牌背；二人模式只显示正上方的一名电脑，三人模式不显示第四席；底牌只在公开后显示正面。组件不持有 `GameEngine`、`GameState` 或 `FullGameState`。

牌型识别与合法动作生成按 `activePlayerCount` 选择规则：二人和三人单副牌模式启用标准的三带一、飞机带单、四带二单和四带两对；四人模式继续沿用原有牌型限制和多级炸弹规则。设置变更只影响下一局，不会改变进行中的牌局。

自定义快捷键由 `src/app/shortcut_settings` 维护稳定功能标识、默认绑定、中文名称、冲突检查和 JSON 往返；旧设置缺少 `shortcuts` 字段时自动使用全部默认值。`ShortcutDialog` 只编辑一份待确认副本；设置单项时在按键列表中用上下光标浏览、空格勾选，一个普通键可与 Control、Shift、Alt 组成组合键。接受后由 `MainWindow` 同步更新 QAction/QShortcut、Qt event、Windows native message、低级键盘钩子与既有 RegisterHotKey 兼容路径。跳格键保留用于 Alt 后的顶层菜单切换和对话框焦点导航。
