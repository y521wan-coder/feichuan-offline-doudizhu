# 架构说明

- `src/core`：108 张牌规则、状态机、计分和公共快照。
- `src/ai`：只接受 `AiObservation` 的地主策略、农民团队策略、叫分和合法动作生成。
- `src/accessibility`：公告调度和 Windows 读屏兼容路径。
- `src/ui`：Qt Widgets 界面与键盘交互。
- `src/persistence`：本地设置、统计、回放和诊断。
- `src/audio`：后续从 UI 中逐步抽离的音频边界。
- `src/app`：游戏应用组合根，不包含网络客户端。
- `apps/updater`：唯一允许链接 Qt Network 的独立 Windows 更新器。

核心安全边界是 `AiObservation`：构造时只注入本家手牌和 `PublicGameSnapshot`，策略不得持有 `GameState` 或 `FullGameState`。
