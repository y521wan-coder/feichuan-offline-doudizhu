# 架构说明

- `src/core`：108 张牌规则、状态机、计分和公共快照。
- `src/ai`：只接受 `AiObservation` 的地主策略、农民团队策略、叫分、合法动作生成和 `StrategicSearchEvaluator`。后者先做全候选快速牌型评估，再对难度限定的最佳候选做有限深度拆牌束搜索，并从公开牌池构造确定性可能牌局估算控制权。
- `src/accessibility`：公告调度和 Windows 读屏兼容路径。
- `src/ui`：Qt Widgets 界面与键盘交互；`CardTableWidget` 只接收公共快照、真人手牌和选中牌 ID，以程序绘图方式提供无鼠标交互的可视牌桌。
- `src/persistence`：本地设置、统计、回放和诊断。
- `src/audio`：后续从 UI 中逐步抽离的音频边界。
- `src/app`：游戏应用组合根，不包含网络客户端。
- `apps/updater`：唯一允许链接 Qt Network 的独立 Windows 更新器。

核心安全边界是 `AiObservation`：构造时只注入本家手牌和 `PublicGameSnapshot`，策略不得持有 `GameState` 或 `FullGameState`。

公开信息推断不等于读取暗牌：它只从本家手牌、已经打出的牌、地主确定后公开的底牌、公开剩余张数、叫分和过牌状态生成多组可能分配。相同公开观察和决策种子会得到相同样本及结果；真实对手手牌不进入评估器。

可视牌桌遵守同一隐藏信息边界：三名电脑玩家只显示 `PublicGameSnapshot` 中的剩余张数与牌背，底牌只在公开后显示正面；组件不持有 `GameEngine`、`GameState` 或 `FullGameState`。
