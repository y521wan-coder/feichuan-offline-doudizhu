# 独立更新协议

## 固定身份

- 服务地址：`https://update.327802521.xyz`。
- 检查接口：`GET /api/v1/updates/check`。
- 产品标识：`feichuan_offline_doudizhu`。
- 平台：`windows`。
- 通道：`stable`。
- 游戏本体、core、ai、ui 不链接 Qt Network；只有“飞船单机斗地主更新器.exe”联网。

客户端检查更新时必须传入 `product_key`、`platform`、`channel` 和 `current_version`，并且只使用接口返回的 `download_url`，不得自行拼接下载地址。

## 返回与验证

有更新时，客户端读取 `latest_version`、`release_notes`、`download_url`、`file_size`、`sha256`、`signature_algorithm`、`signature_payload_version`、`signing_key_id` 和 `signature`。

当前固定签名算法为 RSA 3072 位、PKCS#1 v1.5、SHA-256；签名原文版本为 1。更新器依次验证 HTTPS、文件大小、SHA-256、固定密钥 ID 和数字签名，任一失败都删除临时文件并禁止执行安装包。

本方案不依赖公开 CA 的 Windows Authenticode 证书，因此首次人工运行安装包时 Windows 仍可能显示未知发布者或 SmartScreen 提示。软件内部自动更新的真实性由内置固定公钥保证。

## 发布密钥

- 公钥和密钥 ID 可提交到仓库并内置于更新器。
- 私钥不得进入仓库、安装包、服务器、文档或日志。
- 当前私钥使用随机密码加密；密码只以 Windows DPAPI 加密数据保存，签名时不需要用户再次输入。
- DPAPI 绑定当前 Windows 用户；迁移电脑或重装系统前必须另行制定密钥迁移或双钥轮换方案。
- 普通版本发布禁止替换产品固定公钥。

## 后续版本发布

例如发布 1.1：

```powershell
Set-Location 'D:\飞船单机斗地主'
Set-Content -Encoding UTF8 version.txt '1.1'
.\tools\build_release.ps1 -Package
python .\tools\sign_release.py
python .\tools\publish_update.py --ssh-key C:\apple1007
```

发布脚本会验证版本、文件名、文件大小、SHA-256 和固定公钥签名，再通过 SSH/SCP 上传。服务器只保留同一产品、平台和通道的最新版本；新版本必须严格高于当前版本。

更新失败、断网或取消不得终止或破坏游戏；更新器不得读取或上传存档、手牌、统计、回放、设置、自定义音效或日志。
