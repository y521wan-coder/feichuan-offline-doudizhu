第一至第三阶段的可编译重构基线已经完成；第四阶段“重写农民 AI”已完成强制协作层和首批确定性场景，正在继续补高级搜索、公共信息推断与大规模模拟。独立更新器已形成可编译骨架，但发布签名、替换回滚和发布验收尚未完成。

2. 本轮完成内容
- 在 D:\飞船单机斗地主 建立独立项目和全新 Git 历史，只迁入用户自有源码、测试、文档与素材。
- 统一产品名和产品标识；AI 仅保留 Beginner、Intermediate、Advanced（初级、中级、高级）。
- 删除 HeuristicModelPackage、模型文件路径、模型加载/校验、晋级和训练中心通信；新增内置 AiLevelProfile。
- 通过 AiObservation 隔离 AI：策略只接收本家手牌、公共快照、公开叫分状态和独立决策种子。
- 新增 FarmerTeamStrategy、LandlordStrategy 和公共原因码；落实让队友、禁止非例外炸弹/高牌压队友、地主一张守门、立即出完例外、最低代价压地主等规则。
- 叫分阶段隐藏八张底牌；地主确定时公开一次并加入地主手牌；F2 在叫分阶段朗读“底牌尚未公开”，之后可重复查询。
- 将联网更新拆成独立“飞船单机斗地主更新器.exe”；游戏主程序只负责启动更新器，不链接 Qt Network。
- 新增 SHA-256 与 Windows Authenticode 验证入口，更新产品标识为 feichuan_offline_doudizhu。
- 修复地主确定后底牌标签不显示的 UI 回归。
- 将长时引擎模拟拆为两个独立 CTest 进程，保持 500 个种子覆盖并消除五分钟看门狗假失败。
- 本地安装 Qt 6.8.3 开发依赖到忽略目录 Qt，并为中文项目路径增加自动 subst 构建支持。

4. 测试命令和结果
- tools\build.ps1 -Preset debug-x64 -Configure -Build：通过，生成游戏和独立更新器。
- ctest --preset debug-x64 -E "test_engine_simulation|test_ai" --output-on-failure：14/14 通过。
- ctest --preset debug-x64 -R "^test_engine_simulation_" --output-on-failure：2/2 通过，共 500 局中级 AI，500 局正常结束，零非法命令，计分总和均为零；153.35 秒 + 149.99 秒。
- test_ai：通过，其中高级 AI 自动牌局 500/500 正常结束，耗时约 388 秒。
- test_farmer_cooperation：8 个确定性协作/不可见信息场景通过。
- test_main_window_shortcuts：39/39 通过，包括叫分隐藏底牌、地主确定后显示与 F2 查询。
- 静态边界扫描：活动代码无 Master/大师、旧产品标识、模型包和被排除二进制；Qt Network 只由独立更新器及其测试链接。
