飞船AI斗地主单机版玩法说明
============================

一、人数和发牌
1. 四人使用两副牌，共一百零八张。
2. 每人先发二十五张，留下八张底牌。
3. 本游戏采用“明底牌叫分”：进入叫地主阶段时，八张底牌立即向所有参与者公开。
4. 地主确定后取得这八张底牌，共有三十三张，一名地主对抗三名农民。

二、叫地主
1. 随机玩家开始叫分，可以不叫或叫一分、二分、三分。
2. 后叫者必须高于当前最高分，叫三分立即成为地主。
3. 四家都不叫时重新发牌。
4. 每次重新发牌都会产生并公开一组新的八张底牌。

三、胜负
1. 地主先出完全部手牌时地主获胜。
2. 任意一名农民先出完全部手牌时农民方获胜。

四、普通牌型
1. 支持单张、对子、三张、三带一对。
2. 支持至少五张的顺子，二和大小王不能进入顺子。
3. 支持至少三对的连对，二和大小王不能进入连对。
4. 支持不带牌的飞机和飞机带同数量对子。
5. 不支持三带一张单牌、飞机带单张和四带二。

五、比较规则
1. 普通牌必须牌型相同、总张数相同才能比较。
2. 顺子、连对和飞机必须具有相同主体长度。
3. 三带一对和飞机带对只比较主体点数。
4. 连续三家过牌后，由最后实际出牌者重新自由领出。

六、炸弹
1. 四张同点牌叫枪。
2. 一张小王加一张大王叫王炸。
3. 五张同点牌叫炮，六张叫火箭，七张叫导弹，八张叫天炸。
4. 两张小王加两张大王叫双王炸。
5. 等级从低到高为：枪、王炸、炮、火箭、导弹、天炸、双王炸。
