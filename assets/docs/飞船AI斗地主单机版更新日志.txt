飞船AI斗地主单机版更新日志
============================

3.0长期内测音量与设置稳定性修复，2026年8月3日

1. 修复游戏音效和背景音乐音量数字能够修改、但实际响度不随百分比变化的问题。
2. 音效及背景音乐统一使用0%至100%的软件音量缩放，不再依赖部分声卡驱动不支持的设备音量命令。
3. 修复在F5设置中编辑音效音量或背景音乐音量时，设置窗口及游戏界面可能卡死的问题。
4. 为保证稳定，声音开关、音量和音乐模式只在按“OK”确认后统一生效；在设置窗口中按上下光标或输入数字时不再实时操作音频设备，按“Cancel”不应用修改。
5. 修复F5在菜单激活时可能无反应的问题；背景音乐改用稳定的PCM循环播放，普通、激昂和自动模式及音量设置均可用。
6. 开局及F2公开底牌的单张牌不再附加“1张”，对子和三张仍保留必要数量。

3.0长期内测读屏兼容修复，2026年8月3日

1. 修复争渡等读屏能够朗读Alt菜单、但F1和游戏动态状态完全无声的问题。
2. 动态文字改用普通Qt/UIA控件的传统焦点事件，不再依赖Qt 6.8新式公告通知。
3. 传统事件只通知读屏，不移动真实键盘焦点；菜单、叫分、手牌和拿放牌操作保持原样。
4. 版本继续保持3.0，不加入读屏专用DLL或内置语音，不修改玩法、机器人和音效。

版本 3.0 正式版，2026年8月2日

3.0长期内测补充，2026年8月3日

1. 正式发牌改用Windows系统加密随机源和无偏洗牌；固定种子只用于自动测试和训练。
2. 初级、中级、大师级统一使用本地StandardAI和三个独立模型，最大决策预算为150、450、1000毫秒。
3. 机器人可利用公开底牌及完整公开叫分、出牌和过牌历史，但不能读取其他玩家隐藏手牌。
4. 训练模型按新大师、旧大师转中级、旧中级转初级的顺序自动更新；模型损坏时回退内置三级逻辑并显示一次可访问警告。
5. 本补充不增加玩法，不改变现有快捷键、音效和标准Qt/UIA无障碍路线，版本号继续保持3.0。

版本 2.9，本地修订，2026年8月2日
--------------------------------

1. 删除远程大模型接管、API 认证管理、模型测试和联网决策代码，软件不再提供远程机器人模式。
2. 机器人模式固定为初级、中级、大师级三档，三名电脑玩家全部使用本地逻辑。
3. 删除远程决策诊断、在线教师数据学习链和不再需要的 Qt SQL、Concurrent 运行组件；旧用户数据文件不会被覆盖安装删除，但软件不再读取。
4. 牌局规则、键盘、读屏、音效、明底牌、F2、更新和统计等其他功能保持不变。

版本 2.9，早期本地构建（已被上述修订替代）
----------------------------------------------

1. 远程 AI 改为只使用玩家选择的一个模型，新 DeepSeek 配置默认使用 deepseek-v4-flash 非思考模式，不再自动切换高性能模型，减少无效等待和费用。
2. 提示词升级为 compact_v3，每次最多发送 24 个经过保留规则筛选的合法候选；远程模型仍只能返回 action_id，最终由本地规则引擎复验。
3. 远程请求增加 8 秒绝对超时、连续失败暂停和认证失败保护；失败立即降级本地高级 AI，不自动重试扣费。
4. API 认证管理新增“测试当前模型”，只有玩家手动点击才发送最小请求，并显示合法动作结果和耗时。
5. 修复长按按键被误判为大量独立操作、重复 Qt 无障碍事件和逐条日志写入可能导致的逐渐卡顿。
6. 程序继续只使用 Qt/UIA 标准无障碍，不内置读屏或语音，不加载 NVDA、争渡、保益专用 DLL；诊断现在明确区分“公告请求已提交”和“读屏实际朗读”。
7. 保留 2.8 拿放牌静默、F2、明底牌、音效队列、飞机带对子和“双王枪毙”等既有行为。

版本 1.5，2026年7月31日
----------------------

1. 新增“启用读屏官方接口兼容模式”开关，默认关闭并使用标准 Qt/UIA 无障碍；只有游戏动态内容完全无声时才需要开启。
