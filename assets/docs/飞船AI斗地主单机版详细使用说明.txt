飞船AI斗地主单机版详细使用说明
================================

一、首次启动

长期内测中的三档机器人说明：初级、中级和大师级全部在本机运行，使用同一个StandardAI引擎和三个独立模型，最大决策预算分别为150、450和1000毫秒。训练中心安装新模型时，新模型成为大师，原大师变中级，原中级变初级，旧初级删除。机器人只能看到自己的手牌和公开信息，不能读取其他玩家隐藏手牌。
1. 软件新安装或更新后第一次启动，会自动打开当前版本的更新说明 TXT 文件。
2. 请使用 Windows 文本阅读程序和读屏软件正常逐行阅读。
3. 按 Ctrl+Home 到文件开头，按 Ctrl+End 到文件结尾。
4. 按 Alt+F4 关闭 TXT 文件后即可继续使用游戏。
5. 更新说明只自动打开一次；本详细说明可从“帮助、详细使用说明”重新打开。

二、开始、停战和退出
1. 进入主界面后按 F1 开战。
2. 牌局中按 F1 停战，再按 F1 恢复。
3. 一局结束后按 F1 开始下一局。
4. 牌局中按 Esc 放弃当前残局并返回未开战主界面。
5. 结算页按 Esc 返回主界面。
6. 按 Alt+F4、Ctrl+Q，或选择“游戏、退出”关闭软件。

三、菜单操作
1. 单按 Alt 进入菜单模式。
2. 按 Tab 或 Shift+Tab 在“游戏、设置、帮助”三个顶层菜单之间循环。
3. 按回车、空格、下光标或右光标展开菜单和子菜单。
4. 按上、下光标浏览菜单项目，按回车执行。
5. 按 Esc 返回上一层或关闭菜单。

四、基本玩法
1. 四人使用两副牌，共一百零八张。
2. 每人先发二十五张，留下八张底牌；进入叫地主阶段时底牌立即公开，地主取得底牌后共有三十三张。
3. 真人固定为玩家一，其余三家由本地机器人操作。
4. 一名地主对抗三名农民。地主先出完牌时地主获胜；任一农民先出完牌时农民方获胜。
5. 随机一名玩家开始叫分，可以不叫或叫一分、二分、三分。
6. 后叫者必须高于当前最高分；叫三分立即成为地主。
7. 四家都不叫时重新发牌。
8. 每次发牌完成后会自动朗读一次八张公开底牌；真人和三名本地机器人在叫分时获得相同的公开底牌信息。

五、叫地主操作
1. 轮到自己叫分时，按 Tab 或 Shift+Tab 在“不叫、一分、二分、三分”按钮间移动。
2. 按回车或空格确认。
3. 也可以按大键盘数字零、一、二、三直接选择。
4. 小键盘数字不会触发叫分。
5. 叫分期间可随时按 F2 重复查询八张公开底牌，查询不会改变焦点或执行叫分。

六、浏览手牌
1. 左、右光标按点数组浏览尚未拿起的牌，例如“四张三”。
2. 浏览手牌时只播报牌面，不播报“已选择”或“选中”。
3. Home、End 移动到首组或末组尚未拿起的牌。
4. Shift 加左、右光标逐张浏览尚未拿起的实体牌。
5. 已经拿起的牌会暂时离开全部浏览路径，放下后才重新出现。

七、拿牌和放牌
1. 按上光标拿起当前一张牌，读屏不播报任何内容。
2. 按 Ctrl 加上光标，拿起当前点数的全部未拿牌。
3. 按下光标，按照拿起顺序放下一张牌。
4. 按 Ctrl 加下光标放下全部已拿起牌。
5. 上述拿牌和放牌操作均保持读屏静默，但继续播放原有拿起、放下游戏提示音。
6. 别人行动期间也可以提前拿牌、放牌和重新组合。

八、出牌和过牌
1. 只有轮到玩家一时，按回车才能提交当前拿起的牌。
2. 软件会再次检查牌型是否合法以及是否能够压过桌面牌。
3. 按空格键过牌；自由领出时也可以使用。
4. 别人行动期间不能提前提交或过牌。
5. 连续三家过牌后，由最后实际出牌者重新自由领出。

九、牌点顺序和普通牌型
1. 点数从小到大为三、四、五、六、七、八、九、十、钩、圈、凯、尖、二、小王、大王。
2. 单张是一张任意点数的牌。
3. 对子是两张相同点数的牌。
4. 三张是三张相同点数的牌，播报时采用“三个五”这类说法。
5. 三带一对由三张相同点数加一个对子组成；不支持三带一张单牌。
6. 顺子由至少五个连续点数组成，每个点数使用一张牌；二、小王和大王不能进入顺子。
7. 连对由至少三个连续对子组成；二、小王和大王不能进入连对。
8. 飞机主体由至少两个连续三张组成；二不能进入飞机主体。
9. 飞机可以不带牌，也可以给每组连续三张各带一个对子。
10. 飞机允许使用主体点数剩余的牌组成对子翅膀。
11. 不支持飞机带单张，也不支持四带二。

十、牌型比较
1. 普通牌必须牌型相同、总张数相同才能比较。
2. 顺子、连对和飞机还必须具有相同的主体长度。
3. 组合牌只比较主体点数，不比较所带对子点数。
4. 普通牌不能压过炸弹；炸弹可以压过普通牌。

十一、炸弹等级
1. 枪：四张相同点数的牌。
2. 王炸：一张小王加一张大王，可以压过四张枪。
3. 炮：五张相同点数的牌。
4. 火箭：六张相同点数的牌。
5. 导弹：七张相同点数的牌。
6. 天炸：八张相同点数的牌。
7. 双王炸：两张小王加两张大王，是最高等级炸弹。
8. 炸弹等级从低到高为：枪、王炸、炮、火箭、导弹、天炸、双王炸。
9. 同一等级的同点数炸弹按主体点数比较；更高等级炸弹直接压过较低等级炸弹。

十二、查询快捷键
1. F11 播报当前行动玩家的昵称。
2. F12 播报最后实际出牌者的昵称和牌型。
3. Alt 加大键盘一、二、三、四，查询四家身份和剩余牌数。
4. F2 查询底牌。
5. Alt+F 查询当前分数、基础分和倍数。

十三、设置和声音
1. 按 F5 打开设置。
2. 可以在初级、中级、大师级三种本地机器人模式之间选择，并调整自动过牌时间、游戏音效、音量、真人声线和背景音乐。
3. 设置菜单可以修改四名玩家的昵称。
4. 背景音乐默认关闭，可以选择自动、背景、普通或激昂模式。
5. 玩家二、玩家三默认使用男声，玩家四默认使用女声，真人可以选择男声或女声。

十四、软件更新
1. “每天启动软件时自动检测一次更新”默认开启，同一天只自动检查一次。
2. 可以从“设置、手动检查更新”随时检查。
3. 发现新版本后，可以选择立即更新、忽略此版本或以后不再提醒。
4. 忽略此版本后，只有出现更高版本才会再次提醒。
5. 以后不再提醒会关闭自动检查，但手动检查仍然可用。
6. 安装包下载完成后必须通过 SHA-256 校验，校验失败不会运行安装包。

十五、帮助和支持
1. “帮助、快捷键”打开独立的快捷键 TXT 文件。
2. “帮助、玩法说明”打开独立的玩法说明 TXT 文件。
3. “帮助、详细使用说明”重新打开本文件。
4. “帮助”菜单最下面的“喜欢作者”显示微信付款二维码。
5. 喜欢请随心打赏一下，鼓励开发者继续完善增加软件好玩的功能。
读屏和诊断：程序固定使用 Qt/UIA 标准无障碍。动态状态写入普通状态控件并发送传统焦点事件，兼容能够朗读菜单但不支持新式 UIA 公告通知的读屏；事件不会移动真实键盘焦点。程序不加载争渡、保益或 NVDA 官方接口 DLL，也不使用内置语音库。遇到读屏问题时，可进入 Alt 菜单的“帮助”，执行“复制诊断信息”，再把剪贴板内容发给维护人员。诊断报告会自动排除其他玩家隐藏手牌和真实用户目录，也不会自动联网发送。
