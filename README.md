# 四人斗地主

飞船AI斗地主单机版是一款 Windows 桌面无障碍四人斗地主游戏。

## 系统要求
- Windows 10 x64（已以LTSC 19044为首要兼容目标）或 Windows 11 x64
- 支持NVDA、保益、争渡读屏

## 快速开始
1. 运行 FourPlayerDoudizhu.exe
2. 按 F1 开战，再次按 F1 停战或恢复
3. 使用左右光标按组浏览尚未拿起的手牌，上光标拿牌，回车出牌
4. 按 Tab 或 Shift+Tab 只在“游戏、设置、帮助”三个顶层菜单间循环
5. 牌局中按 ESC 立即放弃残局；结算列表中按 ESC 返回未开战主界面

## 声音与数据
- 真人出牌声线可选男声或女声；玩家二、三固定男声，玩家四固定女声。
- 背景音乐默认关闭，可设置独立音量及自动、背景音乐、普通、激昂模式。
- 未完成牌局不保存、不恢复；设置、玩家名称、统计和诊断数据继续保留。
- 正式游戏没有局数上限，可无限开始新牌局；“5000 局”仅指发布前自动压力测试次数。
- 正式发牌使用Windows系统加密随机源和无偏洗牌；测试固定种子不会用于真人牌局。
- 初级、中级和大师级使用同一本地AI引擎及三个独立模型，不联网推理，也不读取其他玩家隐藏手牌。
