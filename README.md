# 飞船斗地主

面向 Windows 的无障碍斗地主。启动后可选择纯单机或 AI 对战。两种模式均支持二人玩法（一副牌 54 张、双方各 17 张、3 张底牌、17 张盖牌）、三人玩法（一副牌 54 张、每家 17 张、3 张底牌）和四人玩法（两副牌 108 张、每家 25 张、8 张底牌）。

当前项目由用户拥有完整版权的“飞船AI斗地主单机版”定向重构而来，继续复用 Qt Widgets 界面、键盘操作、读屏路径、规则核心和自有音视频素材。纯单机机器人使用本地固定策略；AI 对战中，1 号位为真人，其余席位共用用户配置的云模型，模型请求由独立的 AI 服务进程发送。

## 产品边界

- 机器人等级：初级、中级、高级。
- 纯单机不启动 AI 服务或发送模型请求；AI 对战仅在用户配置认证并进入该模式后向所选服务商发送决策请求。无账号、匹配、真人联机或云牌局。
- 叫分期间底牌隐藏，地主确定后按所选玩法公开 3 张或 8 张底牌。
- 农民共享团队胜利目标；机器人通过受约束的 `AiObservation` 使用经校验的整桌信息。真实暗牌不会进入公共界面、朗读、回放、统计或诊断日志；AI 对战会把模型决策所需的整桌信息发给用户选定的服务商。
- 本地引擎负责洗牌、规则、合法动作与计分；游戏、独立 AI 服务和更新器分离。断网不影响纯单机游戏。
- 设置中可控制地主首轮是否必须出牌，默认开启；关闭后，真人当地主也可以在首轮过牌。

## 构建

需要 C++20、CMake 3.24+、Ninja、MSVC 和 Qt 6.8（Core、Widgets、Test；独立更新器与 AI 服务使用 Network）。

```powershell
cmake --preset debug-x64
cmake --build --preset debug-x64
ctest --preset debug-x64
```

规则、架构、无障碍与验收要求见 `docs/`。每轮开发状态见 `继续开发说明.txt`。
