# 飞船单机斗地主

面向 Windows 的无障碍单机斗地主。可在设置中选择二人玩法（一副牌 54 张、双方各 17 张、3 张底牌、17 张盖牌）、标准三人玩法（一副牌 54 张、每家 17 张、3 张底牌）或原四人玩法（两副牌 108 张、每家 25 张、8 张底牌）；旧设置继续默认四人玩法。

当前项目由用户拥有完整版权的“飞船AI斗地主单机版”定向重构而来，继续复用成熟的 Qt Widgets 界面、键盘操作、读屏路径、规则核心和自有音视频素材。AI 改为可审查的固定策略，不加载训练模型，也不读取其他玩家暗牌。

## 产品边界

- 机器人等级：初级、中级、高级。
- 完全离线牌局，无账号、匹配、真人联机或云牌局。
- 叫分期间底牌隐藏，地主确定后按所选玩法公开 3 张或 8 张底牌。
- 农民共享团队胜利目标，但机器人只依据本家手牌和公共信息决策。
- 游戏与独立更新器分离；断网不影响游戏。

## 构建

需要 C++20、CMake 3.24+、Ninja、MSVC 和 Qt 6.8（Core、Widgets、Test；独立更新器额外使用 Network）。

```powershell
cmake --preset debug-x64
cmake --build --preset debug-x64
ctest --preset debug-x64
```

规则、架构、无障碍与验收要求见 `docs/`。每轮开发状态见 `继续开发说明.txt`。
