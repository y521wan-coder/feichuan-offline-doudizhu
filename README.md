# 飞船斗地主

面向 Windows 的无障碍斗地主。启动后可选择“离线单机版”“AI 对战模式”或“在线真人版”。三种模式都支持二人玩法（一副牌 54 张、双方各 17 张、3 张底牌、17 张盖牌）、三人玩法（一副牌 54 张、每家 17 张、3 张底牌）和四人玩法（两副牌 108 张、每家 25 张、8 张底牌）。

当前项目由用户拥有完整版权的“飞船AI斗地主单机版”定向重构而来，继续复用 Qt Widgets 界面、键盘操作、读屏路径、规则核心和自有音视频素材。纯单机机器人使用本地固定策略；AI 对战中，1 号位为真人，其余席位共用用户配置的云模型，模型请求由独立的 AI 服务进程发送；在线真人版是独立的 Windows 程序，连接本游戏的联机服务器，服务端直接编译同一份规则源码。

## 产品边界

- 机器人等级：初级、中级、高级。
- 纯单机不启动 AI 服务或发送模型请求。
- 在线真人版需要账号，账号、会话和房间数据只存在联机服务器自己的数据库里，与更新服务数据库分开。主程序、core、ai、原 ui 不链接 Qt Network；只有更新器、独立 AI 服务和独立在线程序联网。
- 叫分期间底牌隐藏，地主确定后按所选玩法公开 3 张或 8 张底牌。
- 农民共享团队胜利目标；机器人通过受约束的 `AiObservation` 使用经校验的整桌信息。真实暗牌不会进入公共界面、朗读、回放、统计或诊断日志；AI 对战会把模型决策所需的整桌信息发给用户选定的服务商。联机网络视图只含公开牌桌状态与收件者自己的手牌。
- 本地引擎负责洗牌、规则、合法动作与计分；游戏、独立 AI 服务、独立在线程序、联机服务和更新器分离。断网不影响离线单机和 AI 对战。
- 设置中可控制地主首轮是否必须出牌，默认开启；关闭后，真人当地主也可以在首轮过牌。在线真人版沿用同一规则，但由服务端判定。

## 构建

需要 C++20、CMake 3.24+、Ninja、MSVC 和 Qt 6.8（Core、Widgets、WebSockets、Test；独立更新器、AI 服务和在线程序使用 Network，在线程序与联机服务使用 WebSockets）。

```powershell
cmake --preset debug-x64
cmake --build --preset debug-x64
ctest --preset debug-x64
```

Linux 联机服务使用独立构建入口 `apps/online_server/CMakeLists.txt`（Debian 12 的 Qt 6.4 与 libsodium），只编译 `src/core`、`src/ai` 的服务端所需源码，不编译 Windows 界面。

规则、架构、无障碍与验收要求见 `docs/`。每轮开发状态见 `继续开发说明.txt`，联机回归结果见 `docs/在线2.3回归表.md`。
